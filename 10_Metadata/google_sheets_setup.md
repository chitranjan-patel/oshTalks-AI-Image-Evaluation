# Google Sheets Integration Setup

## Purpose
This document explains the Google Sheets schema required for storing participant data during the hiring evaluation. Google Sheets is used because Streamlit Cloud's ephemeral filesystem does not support persistent local CSV writes.

## Required Sheet Structure
- **Spreadsheet Name**: Any name (e.g., `JoshTalks_Evaluation_Data`)
- **Worksheet Name**: Must be exactly `Sheet1`

### Exact Column Headers Required
Copy and paste this exact row into Row 1 of `Sheet1`:
```text
participant_id,name,email,age,consent,image_order,overall_choice,reason,timestamp,image_a_model,image_a_prompt_adherence,image_a_visual_quality,image_a_realism,image_a_indian_fit,image_a_ecommerce_usefulness,image_b_model,image_b_prompt_adherence,image_b_visual_quality,image_b_realism,image_b_indian_fit,image_b_ecommerce_usefulness,image_c_model,image_c_prompt_adherence,image_c_visual_quality,image_c_realism,image_c_indian_fit,image_c_ecommerce_usefulness
```
*(Note: These headers perfectly match the DataFrame structure generated by `app.py` in the `save_data()` function.)*

## Data Mapping & Privacy
### Participant Data (Visible to Admin only)
- `name`, `email`, `age`, `consent`
- All ratings and the `reason` field.

### Model Mapping (Admin Dashboard only)
- `image_a_model`, `image_b_model`, `image_c_model`
- **Warning**: These columns contain the true names (e.g., "GPT Image 1"). They exist so the Admin Dashboard can calculate results. They are NEVER displayed to participants to preserve the integrity of the blind A/B/C test.

## Security Warning
Do not make the Google Sheet public. Only share it with the specific `client_email` from your Google Service Account.
