# Josh Talks AI Question 1: Text-to-Image Evaluation for India

## Project Purpose
This project evaluates the performance of state-of-the-art Text-to-Image AI models specifically for the Indian context, focusing on the **Indian Fashion E-commerce** use case. 

## Use Case & Master Prompt
- **Use Case:** Indian Fashion E-commerce
- **Master Prompt:** *(See `01_Prompts/master_prompt.md` for the exact prompt used to generate images)*

## Models Evaluated
1. **OpenAI GPT Image 1**
2. **Google Gemini 2.5 Flash Image**
3. **Google Gemini 3.1 Flash Image Preview**

## Evaluation Criteria
Participants evaluate 3 randomized images blindly on a 1-5 scale across 5 dimensions:
1. **Prompt Adherence:** How well does the image follow the prompt?
2. **Visual Quality:** Is the image high-resolution and artifact-free?
3. **Realism:** Does it look like a real photo?
4. **Indian Contextual Fit:** Does it accurately represent Indian culture, clothing, and demographics?
5. **E-commerce Usefulness:** Could this image be used on an actual shopping platform?

## How to Run Locally
1. Ensure you have Python installed.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python -m streamlit run app.py`

## Google Sheets Architecture & Deployment
The app uses `st-gsheets-connection` for permanent production storage on Streamlit Cloud.
- **Participant Privacy:** Names, emails, and ratings are written securely to a private Google Sheet. Only Admins have access.
- **Blind Mapping:** The app hides model names from participants (Image A, B, C) but saves the true mapping to the sheet for Admin analysis.

### Secrets Configuration (Deployment)
To deploy, you must configure Streamlit Secrets:
1. Copy the contents of `.streamlit/secrets.toml.example`.
2. Replace placeholders with your Google Service Account JSON credentials.
3. Paste into **Streamlit Community Cloud -> Advanced Settings -> Secrets**.
